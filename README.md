# Broward Foreclosure Watch

Build a simple site called "Broward Foreclosure Watch" for South Florida real estate investors. Make a clean home page with a short intro explaining that the site tracks upcoming Broward County foreclosure auctions, ranked by estimated equity, with a "View this week's auctions" button linking to /foreclosures. Add a top navigation bar with "Home" and "Foreclosures". Create a /foreclosures route with a placeholder page for now; the dashboard will be added to it later. Include a footer that says "Data from public county records. Not financial or legal advice.
